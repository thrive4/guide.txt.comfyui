comfy ui
* Preferd v.0.37.0 (5GB installed)
  this is the version I have used and tested
  for this howto / install manual.

get:
https://github.com/Comfy-Org/ComfyUI/releases
for windows click on 'assets' and download:
ComfyUI_windows_portable_nvidia.7z
* maybe download as ComfyUI_windows_portable_nvidia_v0370.7z
  if you want to keep it clear which version you are using ...

Open zip after downloading and copy content to desired location.

for apple silicon (M1 and up):
https://docs.comfy.org/installation/desktop/macos
or:
https://www.earngenix.com/tutorials/install-comfyui-mac
Ehhr good luck have not tested but should work ...

for linux distro's:
https://docs.comfy.org/installation/desktop/linux
Not for the faint of heart again not tested by me but should work ...

More info:
https://docs.comfy.org/changelog
Check the open tickets:
https://github.com/Comfy-Org/ComfyUI/issues
4.2k at time of writing so this is going to a rough ride ...

Tips:
For more on using comfyui and other tips see 'using comfyui'
further down in this howto / manual.

After installing you can add the following models step by step.
But first it might be handy to copy the contents of the following
bundeld zip files to their respective folders under comfyui:
comfyui 101 workflows.zip
comfyui 101 custom node minimax h3 clipprojection.zip
comfyui 101 custom nodes batch and logging.zip
comfyui 101 custom nodes whisper and chatterbox.zip
comfyui 101 tools.zip
comfyui 101 input data.zip

This one is a bit large so download it from my github repo at:

comfyui 101 python libs whisper and chatterbox.zip
contains all python libs needed for whisper and chatterbox
also make sure you have copied:
comfyui 101 custom nodes whisper and chatterbox.zip

Start with qwen3 vl chat and image description
it's just one model and a simple workflow to get
a hang of things.

The total package comfyui and all mentioned models
tallies up to ~85GB ....

* option B
fast and best motion but difficult to implement needs
comfy ui v0.34.0 or up
using clip projection allows minimax h3 to run faster on ~8GB vram.

minimax h3
\comfyui
  \custom_nodes
   comfyui-clipproj-main

quick install:
use bundeld comfyui 101 custom node minimax h3 clipprojection.zip
copy contents in to \comfyui\custom_nodes folder

or manual get:
https://github.com/nicolab28/ComfyUI-ClipProj
click on green button 'code' and select / click on 'download zip'

Open zip and copy contents to folder described above.

\comfyui
  \models
    \clip_projections (part of custom node comfyui-clipproj-main)
     mmh3-4b-ClipProj-v3.1.safetensors
    \diffusion_models  (tricky is nsfw model but the smallest there is @2026)
     10Eros_Max_h3_TURBO-hybrid_beta5_w4a8_14gb_optimized.safetensors
    \text_encoders
     qwen3vl_4b_fp8_scaled.safetensors
    \vae
     minimax_h3_audio_vae_fp32.safetensors
     minimax_h3_video_vae_int8_convrot.safetensors

Tips:
Use work flow minimax_h3_promptgen.json (in \comfyui\user\default\workflows)
for a more easy way of generating the minimax h3 prompt format.

minimax H3 can generate audio as well but it
would be wise to start with disabling that and
keeping
overall_soundscape:
N/A
non_diegetic_music:
N/A
in the prompt to save RAM and reduce rendertime of clip.
