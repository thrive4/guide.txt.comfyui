## comfyui install guide [![Github All Releases](https://img.shields.io/github/downloads/thrive4/guide.txt.comfyui/total.svg)]()
basic guide for **manual** install of\
comfyui and a select set of models\
on windows and in part on other os's

## usage
read comfyui 101.txt and comfyui 101 basic usage.txt\
get companion zip files under release
helps a lot in setting up and using comfyui.

## install
add comfyui 101 zips see releases

## requirements
windows 10(22h2)\
nvidia drivers 5xx.xx and up\
minimal 8GB vram / 16GB dram4\
for running most of the mentioned models\
or M2 and up on apple silicon.

## performance
windows 10(22h2)\
5060 rtx 8GB vram\
intel 13 13000 / 16GB dram4\
rendertimes:\
most models ~20sec / cold run * 2 ~40sec\
exception t2v / i2v 5sec video ~130sec
